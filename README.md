# Fitness and Nutrition Expert System

> Academic Project | Artificial Intelligence | Expert Systems

## Description

An Expert System developed in Python that provides **personalized advice** on nutrition and physical training. The system utilizes production rules (IF-THEN), a forward-chaining inference engine, and an explanation module to justify every recommendation it generates.

---

## System Architecture

```text
examen/
├── main.py              ← Entry point and main orchestrator
├── knowledge_base.py    ← Knowledge base (IF-THEN rules)
├── inference_engine.py  ← Inference engine (forward chaining)
├── calculations.py      ← Core calculations: BMI, BMR, TDEE, macros
├── nutrition.py         ← Dietary plans categorized by goal
├── training.py          ← Workout routines (home/gym)
├── user_profile.py      ← User data model
├── database.py          ← Local JSON persistence
├── ui.py                ← Console interface (CLI)
├── gui.py               ← Web interface (Streamlit)
└── app_desktop.pyw      ← Native desktop interface (CustomTkinter)

## Core Components

### Knowledge Base
- **19 production rules** organized by category:
  - Nutrition
  - Training
  - Progress Tracking
  - Health Alerts
- **Object-Attribute-Value (OAV)** knowledge representation.

### Inference Engine
- **Strategy:** Forward Chaining.
- Evaluates all production rules against the user's profile.
- Automatically triggers every rule whose conditions are satisfied.

### Automated Calculations

| Metric | Formula |
|--------|---------|
| **BMI (Body Mass Index)** | `weight / height²` |
| **BMR (Basal Metabolic Rate)** | Mifflin-St Jeor Equation |
| **TDEE (Total Daily Energy Expenditure)** | `BMR × activity_factor` |
| **Target Calories** | `TDEE ± goal_adjustment` |

### Explanation Module
Each triggered rule provides a natural language explanation describing the reasoning behind the recommendation, ensuring system transparency and interpretability.

# Requirements

- Python **3.10+**
- `rich` (Console Interface)
- `customtkinter` (Desktop Interface)
- `streamlit` (Web Interface)

Install dependencies:

```bash
python -m pip install rich customtkinter streamlit
```

Launches the native desktop application without displaying a background terminal.

```bash

## 2. Web Interface (Streamlit)

```bash

# System Limitations

This expert system provides **general fitness and nutrition guidance** based on established principles and predefined knowledge rules.

It **does not replace** professional medical advice, diagnosis, or treatment provided by healthcare professionals, registered dietitians, clinical nutritionists, or certified personal trainers.

Users with chronic illnesses, injuries, or special medical conditions are strongly encouraged to seek professional medical supervision before following any recommendation generated by the system.
