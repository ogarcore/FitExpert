# `assets/exercises/` — Imágenes de ejercicios

Convención: cada ejercicio tiene un `slug` estable derivado de su nombre.
Coloca la imagen con el nombre del slug y una de estas extensiones:
`.png`, `.jpg`, `.jpeg`, `.webp`.

- Ruta: `assets/exercises/<slug>.png` (por ejemplo)
- Tamaño recomendado: **1200×900 px** (proporción 4:3), fondo blanco limpio.
- Formato recomendado: **WebP** (o PNG). La app la muestra con `object-fit: contain`
  sobre un «lienzo» blanco integrado en la tarjeta oscura.
- Mientras no exista el archivo, la app muestra un placeholder con el diseño.
